# Architecture

nibwarden's design documents, written in Chinese as the project was built. Each records
the decisions of a phase, the reasons for them, and what was tested.

- [phase1.md](phase1.md): the daemon, the CLI, the SSH agent and git signing; the vault
  model, the control protocol and the security model.
- [phase2.md](phase2.md): the desktop: the platform layer, the unlock and approval windows,
  quick access, the main window, live sync, the tray icon, packaging, sign-in and
  registration, and the browser extension.
